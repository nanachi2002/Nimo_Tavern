What is (and isn't) recorded

  • Recorded: one row per day with plain counters (visitors, page views, wiki views, logins, sign-ups, relay calls), and the number of accounts active per day, week and month.
  • Unique visitors are counted in server memory only, with a keyed hash of the IP and a random salt that is thrown away at the end of the day. IP addresses are never written to disk and can't be recovered or linked across days.
  • Active accounts use a dedupe table of keyed hashes that only holds the current day/week/month and is purged when the period ends, so past activity can't be tied to any account.
  • Never recorded: IPs, user agents, usernames in stats, which pages a person visited, per-user history, or anything about chats, characters or keys. There is no per-user list anywhere in this panel.
  • Totals such as accounts and storage come from data the server already needs to function (account count, blob sizes).

This panel is only served to the admin account; everyone else sees a normal "not found" page.
