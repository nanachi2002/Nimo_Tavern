SillyTavern is only the interface. To get replies it needs to talk to an AI model through an API. Think of it like this: the provider (OpenRouter, OpenAI…) runs the brain, you rent it with a secret API key, and the tavern sends your conversation to it.

The five words you need

WordMeaning
ProviderThe company or program running the AI: OpenRouter, OpenAI, Anthropic, Google, DeepSeek, or your own PC.
API keyA long secret password that lets you use the provider (and be billed by it). Treat it like a credit card number.
Endpoint / URLThe web address SillyTavern sends requests to. Official providers have a built-in one; for your own server you type it in.
ModelThe specific AI you want to use from that provider (some are cheap and fast, some are smart and expensive).
TokenA piece of a word (about ¾ of a word). Providers charge per token, and every model has a maximum number it can read at once.

Chat Completion vs Text Completion

In the panel you first choose an API type:

  • Chat Completion: for modern hosted models (OpenAI, Claude, Gemini, DeepSeek, OpenRouter…) and anything "OpenAI-compatible". The provider handles the formatting. Start here
  • Text Completion: for local or self-hosted engines (KoboldCpp, Ollama, text-generation-webui, vLLM…) where SillyTavern builds the raw text prompt itself using the instruct template.
  • Others (KoboldAI classic, NovelAI, AI Horde…) exist but are niche.

Walkthrough: OpenRouter

OpenRouter is the easiest first choice: one account and one key give you hundreds of models (several are free), and you pay only for what you use.

  1. Get a key Sign up at openrouter.ai, open Keys and create one. Copy it right away; you can't view it again. Add a small amount of credit if you want paid models, and consider setting a spending limit on the key.
  2. Open API Connections Click the plug icon.
  3. Choose Chat Completion, then the source OpenRouter
  4. Paste your key Click Connect (or press Enter). The status dot turns green when the key is accepted.
  5. Pick a model Use the Model list. Free models say "free" in the name; the list also shows context length and price.

Where does my key go?

Your key is saved encrypted with your other settings, so the NimoTavern server can't read it. When you chat, your browser sends the request straight to the provider; the key never passes through NimoTavern (unless you enable the optional relay, see below).

Provider cheat sheet

Type: Chat Completion → OpenRouter. Key from openrouter.ai/keys. Best for trying many models with one key; has free models and "auto" routing.

Type: Chat Completion → OpenAI. Key from platform.openai.com (API keys page). Billing is separate from a ChatGPT subscription: you need API credit.

Type: Chat Completion → Claude. Key from the Anthropic Console (console.anthropic.com). Great at long, nuanced roleplay; needs prepaid credit.

Type: Chat Completion → Google AI Studio. Key from aistudio.google.com (Get API key). Has a free tier with rate limits and very long context.

Type: Chat Completion → DeepSeek. Key from platform.deepseek.com. Very cheap per token.

Type: Chat Completion → Custom (OpenAI-compatible) and enter the server URL, or Text Completion with the matching engine (KoboldCpp, Ollama…). See the local models section below.

Model names, prices and free tiers change often. Always check the provider's own page for current details. The steps above (type → source → key → connect → model) stay the same.

Custom endpoint (any OpenAI-compatible server)

  1. Choose Chat Completion → Custom (OpenAI-compatible)
  2. Enter the base URL For example https://my-server.example.com/v1. It usually ends with /v1.
  3. Enter the key (some local servers accept anything, like none).
  4. Enter the model ID exactly as the server names it, or pick it from the list after connecting.

Running a model on your own PC

You can use a model on your own computer, free and fully private. Because NimoTavern runs in your browser, it can reach servers on the same device at http://localhost or http://127.0.0.1.

ProgramAPI typeTypical URLNote
KoboldCppText Completion → KoboldCpphttp://localhost:5001Allows browser access by default.
LM StudioChat Completion → Customhttp://localhost:1234/v1Turn on "Enable CORS" in its server settings.
OllamaText Completion → Ollamahttp://localhost:11434Allow this site via the OLLAMA_ORIGINS setting.
text-generation-webuiText Completion → Generic / Oobaboogahttp://127.0.0.1:5000Start it with its API (and CORS) option enabled.
Phones and other PCs

localhost means "this very device", so a phone can't reach a model running on your PC. Plain http://192.168.x.x addresses are blocked by browsers on secure pages ("mixed content"). To use a home server from your phone, give it an HTTPS address (for example through a tunnel service) and use that as the URL.

The optional relay

Some providers refuse requests that come straight from a web page (a browser rule called CORS). If you see "Failed to fetch" or a CORS error, open Account → Relay:

  • Fallback mode: try direct first, use the relay only if the provider blocks it.
  • Always: every request goes through the relay, which also hides your IP address from the provider.
The trade-off

With the relay on, that request (prompt and key) travels through the NimoTavern server's memory. It isn't logged or stored, but you must trust the server for that moment. It's off by default, and local models can never use it (the server can't see your PC).

Troubleshooting connections

You seeLikely cause and fix
401 / Unauthorized / Invalid keyKey typed wrong, expired, or for another provider. Paste it again with no spaces.
402 / Insufficient credits / quotaNo balance on the provider. Add credit or pick a free model.
429 / Rate limitToo many requests too fast, or a free-tier cap. Wait a minute or switch model.
Failed to fetch / CORS errorThe provider or your local server blocks browser requests. For hosted providers use the relay; for local servers enable CORS as in the table above.
Model not foundThe model ID changed or isn't on your plan. Re-pick it from the list.
Context length exceededLower Context Size in AI Response Configuration to the model's real limit.
Replies cut off mid-sentenceRaise Response Length or enable "Trim incomplete sentences".
Keep costs under control

Create a separate key for the tavern and set a monthly limit on the provider's dashboard. Long chats cost more per message because the whole history is re-sent each time; see context.
