The basics

Type in the box and press Enter (use Shift+Enter for a new line). The AI's reply streams in. While it writes, the send button becomes Stop.

A good roleplay habit: write actions between asterisks and speech between quotes, like *I lean back.* "Tell me more.". The AI mirrors your style, and SillyTavern colors them (italics for actions, a highlight for quoted speech).

Swipes: don't like it? Roll again

Every AI message can have several alternative versions called swipes. Click the right arrow at the bottom right of the last message: if there is no further swipe, a new one is generated. Click the left arrow to go back. The version you stop on is the one the story continues from.

Message actions

Hover (or tap) a message to see its icons. The menu holds the rest.

ActionWhat it does
EditChange the text of any message, yours or the AI's. Editing the AI's lines is how you steer the story or fix mistakes before they spread.
HideKeeps the message visible to you but excludes it from what the AI reads.
CopyCopies the message text.
DeleteRemoves the message (and optionally everything after).
CheckpointCreates a new chat that starts at this point and links back to the original. Perfect for "what if" paths.
BranchLike a checkpoint, but meant for splitting off alternate storylines.
MoveReorders a message.

The options menu

  • Regenerate: throws away the last AI message and writes a new one (it replaces instead of adding a swipe, depending on your settings).
  • Continue: the AI keeps writing the last message from where it stopped. Use it when a reply was cut off.
  • Impersonate: the AI writes a message as you, in your input box, so you can edit or send it. Handy when you're out of ideas.
  • Start new chat / Manage chat files: open, rename, or delete past conversations with this character. Each character can have as many chats as you like.
  • Attach a file: add a document to the chat as extra reference material for the AI.
  • Close chat: go back to the character list.

Guiding the story without writing it

  • Author's Note: a hidden instruction inserted into the prompt every few messages (for example "the story is set in winter, keep the mood tense"). Open it from the options menu. You choose how deep in the chat it sits and how often it's repeated.
  • Quick Replies: a row of buttons that send pre-written messages or run scripts; see Extensions.
  • System messages: /sys text adds a narrator line, see commands.
  • Edit & continue: write the first words of the AI's next reply yourself, then press Continue to make it finish in your direction.

Long chats and memory

The AI doesn't remember the chat, it re-reads it each time, up to the context limit. When the chat is longer than the limit, the oldest messages simply stop being sent. To keep important facts alive, use the Summarize extension, a lorebook, or put key facts in the Author's Note. The context visualizer shows this happening.

Exporting a chat

Chats are stored as .jsonl files (one message per line). You can export a chat from the chat-files manager, or export your entire tavern from Account → Export decrypted backup, see Your data.

Mobile

On a phone, tap a message to reveal its icons, and swipe left/right on the last message to change swipes if your UI theme has gestures enabled.
