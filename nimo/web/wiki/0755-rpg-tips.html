Which AI works best?

RPG mode needs the AI to follow a small format at the end of each reply. Larger models (Claude, GPT-4-class, DeepSeek, Gemini Pro…) do this reliably. Small local models may struggle.

Common questions

No choices appeared

Tap Show my choices above the message box to ask again. If it keeps happening, try a stronger model.

I made a mistake in my build

While playing, anything you bought can be refunded if nothing else depends on it. Points you chose at character creation are locked for that adventure. You can always make a new adventure with the same character.

I want a different world for the same character

The world belongs to the adventure, not the character. Start a new adventure and pick another one. Attributes keep their power, only the names change.

Can I turn an RPG chat back into a normal chat?

No, on purpose. RPG chats are one-way so the game state can't be confused. Make a normal chat with the same character if you want one.

Can the AI cheat?

No. It never rolls the dice, and everything it proposes (damage, money, XP) is clamped by the app. The state is rebuilt from the chat each time, so edits, swipes and deleting messages stay consistent.

Why do I see a lock on a choice?

That action needs a higher attribute than yours (or a perk that lowers requirements). It tells you which one and how much you have.

Does multiplayer work with RPG mode?

Not yet. Multiplayer chats can't become RPG adventures.

Your game is private

Characters, rolls and adventures are saved in your encrypted chats and settings, like everything else in NimoTavern. The server only stores encrypted data.
