The panel controls how the AI writes. You don't need to touch it at first: the default preset works. But a few sliders make a huge difference, and understanding them lets you tune the AI to your taste.

How an AI picks its next word

A language model writes one token at a time. For each position it gives every possible token a score, and the sampler settings decide how to choose among them. Play with the playground to feel it: Precise almost always picks the top word, Wild lets unlikely words through.

The settings, in plain language

SettingWhat it doesTypical
TemperatureRandomness. Low = focused and predictable, high = creative and chaotic. It reshapes the whole distribution (watch the bars flatten).0.7–1.1
Top KOnly the K most likely tokens are allowed. 0 usually means off.off or 40+
Top PKeep the smallest group of tokens whose probabilities add up to P, drop the long tail of unlikely ones.0.9–1
Min PDrop tokens less than X% as likely as the best one. A modern, adaptive way to cut nonsense while keeping variety.0.02–0.1
Repetition penaltyDiscourages repeating recent words. Too high makes the AI avoid normal words and write strangely.1.0–1.15
Frequency / presence penaltyChat-completion versions of the above: lower the odds of words already used.0–0.5
Response length (max tokens)The most the AI may write per reply (not a target). 1 token ≈ ¾ word.250–600
Context sizeHow many tokens of history, card and lore are sent. Set it to what your model supports and your budget allows, see Prompt & context.8k–32k+
StreamingShow the reply as it's written, instead of waiting for the whole thing.On

Which sliders you see depends on the API you picked. Some providers ignore or hide settings they don't support (for example Claude and OpenAI models don't use Top K / Min P in the same way). That's normal.

Presets

A preset is a saved set of values. The preset menu at the top of the panel lets you:

  1. Select a preset from the dropdown to apply it instantly.
  2. Adjust any slider. The preset name gets a "modified" marker.
  3. Save to overwrite, or Save as to make a new one.
  4. Import / export presets as JSON to share them or move them between devices.

Presets are per API type. Chat-completion presets also include the Prompt Manager (below), so people share "jailbreak-free roleplay presets" as a single file.

Prompt Manager (Chat Completion)

With Chat Completion, the panel includes a Prompt Manager: an ordered list of blocks that become the final message list sent to the model. Each block can be toggled on or off and dragged to reorder.

BlockContains
Main PromptThe core instructions ("You are roleplaying as {{char}}…").
Character / Persona / Scenario / PersonalityThe cards' fields, injected where you place them.
World Info (before / after)Triggered lorebook entries.
Chat HistoryThe conversation itself.
Post-History InstructionsFinal reminders after the chat, where the AI listens most.
Custom promptsAnything you write yourself: style guides, formatting rules, reminders.

The little numbers show how many tokens each block costs. If your prompt is too big, this is where you see what to cut.

Recipes

Temperature 0.3–0.6, Min P 0.05. Replies stay on-topic and consistent. Good for tutoring, coding, or strict canon.

Temperature 0.9–1.1, Min P 0.05 (or Top P 0.95), response length 300–500. A reliable default for stories.

Temperature 1.3+ with Min P 0.1 to keep it from derailing. Surprising and fun; expect the occasional odd turn.

Raise temperature slightly, add a small repetition/frequency penalty, edit out repeated phrases from recent messages (the AI copies what it sees), and vary your own writing.
