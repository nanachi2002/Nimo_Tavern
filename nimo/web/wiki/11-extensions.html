Extensions add features to SillyTavern. Open them with the icon: each extension is a collapsible section with its own settings.

What works on NimoTavern

NimoTavern runs SillyTavern's server code inside your browser, so features that only need the interface or your AI provider work normally. A few built-in features rely on machine-learning models running on a server (they'd need to read your plaintext there), so they're turned off on purpose.

Installing third-party extensions

Extensions made by the community (Memory Books, trackers, UI tweaks…) install the same way as on SillyTavern:

  1. Open Extensions and click Install extension.
  2. Paste the extension's GitHub address, like https://github.com/owner/repo (a branch or sub folder works too: …/tree/branch/folder).
  3. The first time, NimoTavern explains what an extension can do. Read it and accept.
  4. The extension appears in the list. It's saved, encrypted, with the rest of your tavern, so it's on your other devices too. Update or delete it from Manage extensions like on SillyTavern.

What an extension can do

An extension is code written by someone else, running in your browser. It can read and change everything in your tavern (characters, chats, settings, API keys) and act as you. Only install extensions from authors you trust.

It can't touch other users or NimoTavern's server: nothing anyone installs ever runs there.

Why extensions are off in multiplayer

A multiplayer session holds other people's messages and personas. To make sure no extension can ever see them, multiplayer runs on its own site, play.nimorp.lol. To your browser that's a different website, so the extensions you install on the main site can't load there or reach it. That's enforced by the browser itself, not just by our code. See Multiplayer.

Why server plugins don't run

Some SillyTavern add-ons come with a server plugin: Node.js code that runs on the server. On your own PC that's fine. On NimoTavern the server is shared by everyone, so a plugin there could read other people's data or take the site down. That's why NimoTavern never runs anyone's code on its server.

Instead, creators can port their plugin to NimoFramework, which runs it in each user's own browser with the same routes. If you'd love to use one, ask its author and point them to that page.

Summarize

Condenses the chat so far into a short recap that is always kept in the prompt, so the AI remembers old events after they scroll out of the context window.

  1. Open Extensions → Summarize.
  2. Choose the source: your main API (simplest) or another connected one.
  3. Set how often to summarize (every N messages or words), or press Summarize now.
  4. Read and edit the summary text: you can fix mistakes or add facts. It's yours.

Quick Replies

A bar of buttons above the message box. Each button sends a prepared message or runs a small script. Examples: "*sighs and continues*", a "Summarize now" button, or a button that toggles a lorebook entry. Create sets in Extensions → Quick Reply, give each reply a label and a message (can use slash commands), then enable the set globally or for a character.

Regex

Finds-and-replaces text automatically. Common uses: hide <thinking> blocks from the displayed message, clean formatting the AI adds, or alter what's sent to the AI without changing what you see. Each script has a find pattern (regular expression), a replacement, and checkboxes for where it applies (user input, AI output, the prompt, display only…). Test with the built-in tester before enabling.

Expressions

Shows a character sprite that changes with their mood (joy, anger, surprise…). Put sprite images in the character's expression folder through the extension's Upload button, named after the emotion (joy.png, sadness.png…). Where the automatic classifier isn't available, set the sprite yourself with a slash command such as /expression-set joy.

Image generation, TTS and others

  • Image Generation: turns the scene into an image prompt, then asks an image provider for the picture. Configure the provider and your key in the extension's panel.
  • TTS: reads replies out loud with your browser's voices or a connected voice provider.
  • Translation: auto-translates incoming and outgoing messages.
  • Token counter & other utilities: small helpers, each documented in its own panel.

Any extension that calls an outside service sends data from your browser to that service. Use ones whose privacy policy you trust, just as with your AI provider.
