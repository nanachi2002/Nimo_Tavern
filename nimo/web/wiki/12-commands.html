Commands worth knowing

CommandWhat it does
/helpShows help and the list of available commands and macros.
/sys textPosts a narrator/system message (not sent as a character).
/sendas name=Mira textPosts a message as a specific character, without calling the AI.
/triggerAsks the AI to write the next reply (useful in groups).
/continueContinues the last message.
/impersonateThe AI writes your next message.
/hide 3-5 / /unhide 3-5Hide or restore a range of messages from the AI.
/cut 4 / /del 2Remove messages by number.
/gen promptGenerates text from a prompt without adding it to the chat; returns it to a script.
/roll 2d6Rolls dice.
/echo textShows a pop-up message to you only.
/setvar key=name value / /getvar nameStores and reads a variable for scripting.

Available commands grow with SillyTavern versions. Use /help in the tavern for the authoritative list for the version you're running.

Chaining and scripting (STscript)

Commands can be chained with | and their output passed along. Quick Replies can hold whole scripts:

/roll 1d20 | /sys You rolled a {{pipe}}!

STscript also has conditions (/if), loops, variables and user input prompts, enough to build small games. Each command's own help (/help <command>) shows its arguments.

Macros

Macros are {{placeholders}} you can write inside cards, lorebook entries, system prompts and even messages. They're replaced just before sending.

MacroBecomes
{{user}}Your persona's name.
{{char}}The current character's name.
{{time}} {{date}} {{weekday}}Your current local time, date and weekday.
{{random:a,b,c}}One of the listed options, picked at random each time.
{{roll:1d6}}A dice roll result.
{{lastMessage}}Text of the last chat message.
{{setvar::name::value}} {{getvar::name}}Set and read a variable inside text.
{{newline}} {{trim}}Formatting helpers.
{{// note}}A comment that's removed before sending.

Example in a character description: {{char}} is in a {{random:grumpy,cheerful,sleepy}} mood today, and it is {{weekday}}.
