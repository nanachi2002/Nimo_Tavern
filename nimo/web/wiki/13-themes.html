NimoTavern keeps SillyTavern's full theming system, and the site pages around it (home, login, this wiki) use the same colors so everything matches. Everything lives in User Settings.

Playground

UI Theme

  1. Open User Settings and find the UI Theme section.
  2. Pick a theme from the dropdown to apply it instantly. Several are included.
  3. Tweak colors: main text, italics, quote, shadow, border, and the tints behind the panels and messages. Each swatch opens a color picker with transparency.
  4. Save with under a new name. Themes can be imported/exported as JSON to share.

Backgrounds

The icon opens the background picker. Click one to apply it. Use Upload to add your own image (it's stored encrypted in your tavern, like everything else). A background can be locked to a specific chat so different stories get different scenery.

Custom CSS

For full control, paste CSS into User Settings → Custom CSS. It takes effect right away and is saved with your settings. Example: bigger quote highlights and rounder messages:

.mes_text q { color: #ffb86c; }
.mes { border-radius: 16px !important; }
#chat { max-width: 900px; margin: 0 auto; }

Colors are CSS variables like --SmartThemeBodyColor and --SmartThemeQuoteColor. Changing a variable is safer than overriding individual elements, and keeps working after updates.

Only paste CSS you understand. CSS can hide buttons (including Logout). Change one thing at a time, keep a copy of your last working CSS, and avoid rules that hide whole panels or buttons you rely on.

Movable UI

Enable Movable UI to drag and resize panels (character, persona, lorebook…) and save the layout as a UI preset, useful on large monitors.
