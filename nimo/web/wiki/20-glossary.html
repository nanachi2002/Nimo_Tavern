Roleplay & AI terms

TermMeaning
APIThe way programs talk to an AI service. You connect SillyTavern to one with an endpoint and a key.
API keyA secret string that identifies and bills you at a provider. See Connect an AI.
Author's NoteA hidden instruction inserted into the prompt at a chosen depth.
Character cardThe file that defines a character: description, greeting, examples. See Characters.
Chat Completion / Text CompletionThe two ways of sending prompts: as a list of role-tagged messages, or as one block of raw text.
Context (window)The maximum amount of text (in tokens) the AI can read at once, including its own reply.
CORSA browser rule that lets a server decide which websites may call it. The reason some providers need the relay.
Greeting / First messageThe character's opening line when a chat starts.
ImpersonateHave the AI write your next message.
Instruct templateThe special tokens/format a local model expects around messages.
Lorebook / World InfoKeyword-triggered notes injected into the prompt. See World Info.
MacroA {{placeholder}} replaced when the prompt is built.
Min P / Top P / Top KSamplers that cut unlikely words, see AI settings.
ModelThe specific AI doing the writing.
PersonaYour own identity in the story. See Personas.
PresetA saved bundle of sampler/prompt settings.
PromptEverything sent to the AI for one reply: instructions, cards, lore, chat.
ProviderThe company or program that runs the model.
Quick ReplyA button that sends a prepared message or script.
RegexA pattern language for finding and replacing text.
SamplerThe setting that decides how the next word is chosen.
Stop stringText that makes the AI stop writing when it appears.
SwipeAn alternative version of an AI message.
TemperatureThe randomness dial, low is focused, high is creative.
TokenA chunk of text (~¾ of a word) that models read and providers charge by.

NimoTavern & security terms

TermMeaning
AES-256-GCMA widely trusted encryption algorithm that also detects tampering. Used for your files.
Argon2idA password-hashing function deliberately slow and memory-hungry to make guessing expensive.
BlobOne encrypted file as the server sees it: an id plus bytes.
CiphertextEncrypted data: unreadable without the key.
DEK (data key)The random 256-bit key that ultimately protects all your data.
End-to-end / zero-knowledgeOnly the endpoints (your devices) hold keys; the server learns nothing about the content.
HKDFA method of deriving several independent keys from one secret.
HMACA keyed fingerprint. Used to turn file names into unguessable ids.
IndexedDBThe browser's built-in database where the local encrypted copy and keys live.
KEK (key-encryption key)The key derived from your password (or phrase) that unlocks the DEK.
Non-extractable keyA key the browser lets code use but never reveal.
Recovery phrase12 words that can unlock your DEK independently of your password.
RelayOptional pass-through for requests that providers block from browsers. Off by default.
Service WorkerA background script in your browser. NimoTavern runs SillyTavern's server code in it.
SessionThe logged-in state on a device, stored as a hashed token server-side.
TurnstileCloudflare's privacy-friendly captcha used on the sign-up page.
